# Lab 3: Fraud Investigation Platform

Target time: 3 hours  
Minimum time: 2 hours  
Deep work version: 5 hours

## Time plan

### Part 1 — Problem understanding: 20 minutes
- Read scenario
- Write clarifying questions
- Define success metrics

### Part 2 — Decomposition: 35 minutes
- Users
- Workflow
- Bottlenecks
- Data model
- State transitions

### Part 3 — System/API design: 35 minutes
- APIs/actions
- permissions
- audit logs
- reliability concerns
- MVP vs V2

### Part 4 — Coding implementation: 60 minutes
- implement starter code
- run tests
- debug edge cases

### Part 5 — Reasoning write-up: 30 minutes
- explain why your design works
- justify tradeoffs
- identify failure modes

### Part 6 — Interview simulation: 20 minutes
- give 90-second answer
- answer follow-up curveballs
- self-grade

## 2-hour path
Do Parts 1, 2, 4, and self-grade.

## 3-hour path
Do all parts.

## 5-hour path
Do all parts, then add one V2 feature and update your design.
