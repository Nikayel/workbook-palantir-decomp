# Lab 7: Learning & Re-engineering Round

Target time: 3 hours  
Minimum time: 2 hours  
Deep work version: 5 hours

## Time plan

### Part 1 — Understanding the Code: 30 minutes
- Read the flawed starter code.
- Write down exactly what it currently does.

### Part 2 — Finding Bugs: 30 minutes
- Identify the 5 logical bugs intentionally placed in the code.

### Part 3 — Writing Tests: 30 minutes
- Write unit tests that prove the bugs exist (they should fail).

### Part 4 — Fixing & Extending: 60 minutes
- Fix the bugs.
- Implement the new requirement.
- Ensure all tests pass.

### Part 5 — Reasoning write-up: 30 minutes
- Explain your refactoring decisions.

## 2-hour path
Do Parts 1, 2, 4.

## 3-hour path
Do all parts.
