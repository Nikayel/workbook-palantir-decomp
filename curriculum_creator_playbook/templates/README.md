# Templates

Clone-me skeletons for authoring a lab. Copy the relevant file into a new `labs/<NN>_<company>_<slug>/` folder and fill it in per `03_workbook_anatomy_and_authoring_standard.md`.

| Template | Becomes | Notes |
|---|---|---|
| `meta_template.yml` | `meta.yml` | required metadata; drives the coverage matrix |
| `lab_readme_template.md` | `README.md` | orientation + time plan |
| `workbook_skeleton.md` | `workbook.md` | the 8-part instrument; strip parts/blanks per tier |
| `solution_reasoning_template.md` | `solution_reasoning.md` | the 9-part answer key (the feedback engine) |
| `flashcards_template.md` | `flashcards.md` | 8–15 generative cards + cadence |
| `rubric_bank.md` | (paste into Part 7) | ready-made countable rubric rows per role |
| `company_pack_template.md` | `company_packs/<new>.md` | for adding an 11th+ company |

**Don't start from a blank file** — start from the closest **gold-standard sample** in `../gold_standard_samples/` and adapt. These templates are the fallback when no sample is close.
