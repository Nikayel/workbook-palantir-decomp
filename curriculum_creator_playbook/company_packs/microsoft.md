# Company Pack — Microsoft

## 1. Snapshot
| Program | For | Length / timeline |
|---|---|---|
| **Explore Microsoft** | freshmen/sophomores (new to the field) | ~12 wk; **rotational** across SWE + PM (Design/Build/Quality), pods |
| **SWE Intern** | juniors/seniors/grad | ~12 wk |
| **PM Intern** | undergrad + master's | ~12 wk; Azure / M365 / Teams / Xbox |
> *Aspire is the new-grad onboarding program, NOT an internship.* Apps open late summer/fall, rolling — listings close when filled.

## 2. Culture & values (hiring signal)
Mission: *"empower every person and every organization on the planet to achieve more."* Three official values: **Respect, Integrity, Accountability**. The central cultural theme is **growth mindset** ("learn-it-all," not "know-it-all" — Dweck) — the **single most important interview keyword**. Leadership framework: **Model–Coach–Care**. Plus One Microsoft, customer/partner obsession.

## 3. What's distinctive
- **Speak growth-mindset authentically** — frame stories around learning from failure, curiosity, collaboration, customer impact. *Demonstrate* it; don't name-drop.
- **Solid CS fundamentals explained well > trick puzzles** (SWE). **Structure without reciting a framework** (PM).

## 4. Assessment artifacts to replicate
- **Codility OA** — 2 coding questions, 90 min, proctored/recorded (~60% hidden-cases bar; trees/DP/graphs/arrays/strings).
- **Final Round / Superday** — 2–3 back-to-back ×45 min (each ~15 min behavioral + rest coding) on **Teams** + shared editor.
- **"As-Appropriate (AA)"** senior-leader round — standard for new-grad, **variable/often skipped for US interns** (some India off-campus include it).
- **OOP/LLD** shows up more than at peers (C#/.NET culture) — e.g., "design an A/B test class."

## 5. Role tracks
**SWE.** Algorithmic, fundamentals-first, one well-scoped problem/round; interns Easy–Medium. Over-index: trees/BST, graphs, linked lists, strings, recursion, hashmaps, DP, **OOD/LLD**. STAR in **every** round, growth-mindset framed. Language: any (C#/Java/Python read most easily).
**PM.** Product design/improvement ("Design Spotify for children," "favorite product + improve"), estimation, behavioral. **Structure invisibly.**
**Technical PM.** "Technical PM" depth varies by org (Azure/platform skews technical). API design + **concept-explainer** ("explain the cloud to a child," "recursion vs iteration," "design an API for 3rd-party payments," "estimate AWS revenue").

## 6. Lab build list
- SWE *workbooks*: `01` **LLD/OOD** ("design an A/B-test class") (Tier 1) · `02` a second **design-a-DS** lab (Tier 2) · `03` Superday **timed mock** (Tier 3) · `04` growth-mindset STAR (Tier 2). DSA + complexity grinding → shared **DSA drill kit**, *not* a workbook.
- PM: `01` product design (no framework names) (Tier 1) · `02` estimation (Tier 2) · `03` behavioral (Tier 2).
- Technical PM: `01` API design (Azure skin) (Tier 2) · `02` concept-explainer lab (Tier 2).

## 7. Authenticity notes
Real surfaces: Azure, Microsoft 365, Teams, Windows, Xbox, GitHub/Copilot, Dynamics. Reward "learn-it-all" framing in keys; penalize "I already knew everything." For LLD use C#-idiomatic class design. **2025–26 context:** ~15k+ cuts (2025) + early-2026 hiring freeze/further cuts → early-career more competitive.

## 8. Sources & confidence
PM/TPM/SWE + company briefs; careers.microsoft.com, igotanoffer, Exponent, Product Alliance, GeeksforGeeks intern reports, devblogs (AA). **Confidence:** high on Codility + growth mindset + AA-for-new-grad; **medium** on intern AA inclusion + conversion.
