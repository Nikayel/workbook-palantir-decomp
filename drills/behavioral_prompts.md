# Behavioral Prompts

Practice answering these out loud using the STAR method:

1. Tell me about a time you had to work with messy or ambiguous data.
2. Tell me about a time you had to push back on a requirement.
3. Describe a time you made a technical tradeoff for speed.
4. How do you ensure your code is maintainable for others?
5. Tell me about a project where you had to understand a complex domain quickly.
