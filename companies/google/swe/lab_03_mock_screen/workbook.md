## Part 7 — SWE Rubric

*Self-grade after the timer goes off. Be honest.*

| Dimension | 5 — Strong | 3 — Adequate | 1 — Weak | Your Score |
|---|---|---|---|---|
| Communication / think-aloud | Clarified before coding, narrated brute force → optimized, explained each step out loud continuously | Coded with some explanation, or explained some parts but went silent for long stretches | Coded silently throughout; interviewer would not know what you were thinking | __ /5 |
| Problem solving | Named brute force AND optimized approach; explained why the optimized works; discussed grouping vs pairing tradeoff if relevant | Found a working solution without articulating alternatives | Got stuck; produced only a brute force or no solution | __ /5 |
| Correctness | All test cases pass; handles empty list, single word, no anagrams, all anagrams, duplicate words | Core logic correct; 1 edge case missed | Fundamental logic error; fails on basic cases | __ /5 |
| Code quality | Clean names, readable without IDE, no magic constants; solution would survive a code review | Functional but verbose or uses confusing variable names | Buggy, unreadable, or would not run without significant fixes | __ /5 |
| Testing and edge cases | Traced at least 3 test cases out loud before declaring done, including empty list and all-anagram case | Traced 1–2 cases | Declared done without testing | __ /5 |
| Complexity analysis | Correct time and space complexity; justified each; compared to brute force | Named a complexity but imprecise or unjustified | No complexity stated | __ /5 |
| Time management | Finished core solution in < 35 min with time to handle curveballs | Finished but no time for curveballs | Did not complete the solution within 45 minutes | __ /5 |

**Total: __ / 35**

## You're Ready When...

- You finish the complete solution (Parts 0–6) in under 30 minutes without opening any other lab
- You trace all test cases correctly without running code
- You answer at least 2 of the 3 curveball scenarios without freezing
- You self-grade ≥ 24/35 on two separate attempts with at least 24 hours between them

If you scored below 24/35: go back to Labs 01 and 02, redo the blank implementation sections, and return to this mock in 48 hours.

If you scored 24–30/35: you're interview-ready for a phone screen. Consider attempting an onsite-level problem next.

If you scored 30+/35: you're in strong shape. Make sure your narration is tight — strong technical scores can still be dragged down by poor communication.
